変更内容: 運用の形を「毎朝買い・4%買い増し・上限300口」から「一定額を持ち続ける」に切り替える（ユーザー決定）。ユーザー回答: 資金150万円で正しい、含み損の限界は約66万円（「300口で約66万円が限界」）、損が続いても待てるのは1年まで。config.yaml v2 節に fixed_loss_limit_jpy・fixed_wait_limit_days・fixed_methods などを追加した。シミュレータは common_utils/fixed_amount.py（テスト先行）、スクリプトは research/fixed_amount_sizing.py、結果は research/trial_log/fixed_amount/。
根拠: research/trial_log/2026-10-01_rule_variants.md で、実データでは同じ平均額を持ち続ける方が、ほぼすべての変種より年率が高く最大ドローダウンが小さかった。ただしその比較は「毎日金額をそろえる・そろえるコストなし」の理想化だったので、実際にできる2つの形で確かめた。

比べた形（手数料あり。往復0.10%を売買のたびに半分ずつ）:
- 買ったまま持つ（hold）: 初日の寄付で決めた金額を買い、売らない。買い足しもしない
- 毎月戻す（monthly）: 21営業日ごとの寄付で評価額を決めた金額に戻す（上がれば売り、下がれば手元資金で買い足す）

保有額の決め方（成績は使わない）: 保有額1円あたりの「始めた時点からの最悪の損」を測り、上限額 = 66万円 ÷ その値。
- 実データ: 開発期間 2021-09-28〜2026-07-03 で開始日を5営業日ずつずらした185通り（開始日から開発期間の終わりまで）
- ブートストラップ: 建値 5,009円から5年分 × 1,000本、トレンドなし／そのまま（2026-10-01_rule_variants.md と同じ作り方）

結果:

| | 買ったまま持つ | 毎月戻す |
|---|---|---|
| 1円あたりの最悪の損（実データ、最悪の開始日） | −52%（2024-03-04 開始） | −64%（2024-05-24 開始） |
| 同（トレンドなし、悪い方5% / 1%） | −79% / −87% | −125% / −179% |
| 同（そのまま、悪い方5% / 1%） | −47% / −66% | −53% / −86% |
| 損が保有額を超えるか | 超えない（最大でも全額） | 超える（下がるたびに買い足すため） |
| 買い足しに要る手元資金（保有額あたり、最大） | 0 | 実データ 0.64、トレンドなし 2.3 |
| 始めた値を1年以上下回ったままになる割合（実データの開始日 / トレンドなし / そのまま） | 22% / 55% / 11% | 17% / 43% / 8% |

買ったまま持つ場合の、保有額ごとの「5年以内に損が66万円を超える」割合:

| 保有額 | 実データの開始日 | トレンドなし | そのまま |
|---|---|---|---|
| 66万円 | 0% | 0%（損は保有額を超えないので、原理的に超えない） | 0% |
| 76万円 | 0% | 1% | 0% |
| 84万円 | 0% | 5% | 0.1% |
| 100万円 | 0% | 17% | 1% |
| 128万円 | 0% | 35% | 4% |

読み取れること:
1. 損の限界を守るには「買ったまま持つ」が向いている。損は保有額を超えないので、保有額を決めれば最悪の損の上限が決まる。毎月戻す形は下落中に買い足すので、損が保有額を超え、手元資金も要る
2. 保有額 66万円なら、株価が0になっても損は66万円まで。84万円なら、トレンドなしでも5年以内に限界を超えるのは5%
3. 「1年まで」は、どの保有額でも守れるとは限らない。トレンドなしの架空の値動きでは、始めた値を1年以上下回ったままになるのが55%。そうなったときにどうするか（持ち続ける／売る）を、あらかじめ決めておく必要がある

注意:
- 配当は入れていない（data/adjust.py は配当を調整しない）。実際の損益は配当の分だけ良くなる
- 損は「始めた時点からの損」。値上がりした後に下がって利益が減る分（ピークからの下落）は含み損に数えていない
- ブートストラップは開発期間の値動きの並べ替えで、2000〜2002年・2008年のような長い下落は作れない
- 試行数（DSR 用）: 形2つ（買ったまま・毎月戻す）を加えて累計 5,347。保有額の候補は成績で選んでいないので数えない

## 決定（2026-10-01、ユーザー回答）
- 保有額は 84万円（「84万円（5%）」）。買ったまま持つ形。config.yaml v2 節の fixed_amount_jpy・fixed_method
- 1年たって買値を下回っていても売らない（「放置」）。config.yaml v2 節の fixed_wait_action
- この保有額で、損が限界の66万円に届くのは買値から約79%下がったとき（66 ÷ 84）。株価が0になったときの損は84万円
- 資金150万円のうち残りの66万円は使わない（買い足しに回さない）
- 想定（トレンドなしの架空の値動き、5年）: 損が66万円を超える割合 5%、買値を1年以上下回ったままになる割合 55%。上昇トレンドが続いた開発期間の値動きでは、どの開始日でも66万円を超えなかった
